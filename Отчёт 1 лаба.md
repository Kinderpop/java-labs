Текст Задачи

С помощью операции остатка от деления на 10 (% 10) и взятия модуля (Math.abs) находится последняя цифра числа. Затем число делится нацело на 10, и аналогично находится предпоследняя цифра. Метод возвращает сумму этих двух цифр.

Задание 2
Задача 1
Текст Задачи
Дана сигнатура метода: public int abs (int x); 
Необходимо реализовать метод таким образом, чтобы он возвращал модуль числа х (если оно было положительным, то таким и остается, если он было отрицательным – то необходимо вернуть его без знака минус).

Алгоритм Решения
Проверяется знак числа x. Если оно отрицательное (x < 0), вызывается встроенный метод Math.abs(x) для превращения его в положительное. Если число изначально неотрицательное, оно возвращается без изменений.

Задача 2
Текст Задачи
Дана сигнатура метода: public double safeDiv (int x, int y); 
Необходимо реализовать метод таким образом, чтобы он возвращал деление x на y, и при этом гарантировал, что не будет выкинута ошибка деления на 0. При делении на 0 следует вернуть из метода число 0.

Алгоритм Решения
Сначала проверяется делитель y. Если он равен 0, метод возвращает 0 во избежание критической ошибки деления на ноль. В противном случае x приводится к типу double и делится на y для получения точного вещественного результата.

Задача 3
Текст Задачи
Дана сигнатура метода: public bool is35 (int x); 
Необходимо реализовать метод таким образом, чтобы он возвращал true, если число x делится нацело на 3 или 5. При этом, если оно делится и на 3, и на 5, то вернуть надо false. Подсказка: оператор % позволяет получить остаток от деления.

Алгоритм Решения
Первое условие проверяет, делится ли число x одновременно и на 3, и на 5 (то есть на 15) — если да, возвращается false. Второе условие проверяет, делится ли число хотя бы на одно из них. Если делится только на одно, возвращается true.

Задача 4
Текст Задачи

Необходимо реализовать метод таким образом, чтобы он возвращал строку, которая включает два принятых методом числа и корректно выставленный знак операции сравнения (больше, меньше, или равно).

Алгоритм Решения
Сравниваются два числа. С помощью конструкции if-else определяется математическое отношение между ними, после чего формируется и возвращается текстовая строка вида "x>y", "x<y" или "x=y".

Задача 5
Текст Задачи
Дана сигнатура метода: public int max3 (int x, int y, int z); 
Необходимо реализовать метод таким образом, чтобы он возвращал максимальное из трех полученных методом чисел. Подсказка: идеальное решение включает всего две инструкции if и не содержит вложенных if.

Алгоритм Решения
Изначально переменная max принимает значение первого числа x. Затем последовательно проверяются оставшиеся числа: если y больше текущего max, оно становится новым максимумом; аналогично проверяется z. Метод возвращает итоговое наибольшее значение.

Цикл сканирует массив в обратном направлении — справа налево (от последнего индекса к нулевому). При первом же совпадении с числом x метод возвращает этот индекс (который для массива является последним вхождением). Если совпадений нет, возвращается -1.

Задача 4
Текст Задачи
Дана сигнатура метода: public int[]add (int[] arr, int x, int pos); 
Необходимо реализовать метод таким образом, чтобы он возвращал новый массив, который будет содержать все элементы массива arr, однако в позицию pos будет вставлено значение x.

Алгоритм Решения
Проверяется корректность индекса pos. Создается новый массив, размер которого на 1 больше исходного. С помощью System.arraycopy в него сначала копируется часть старого массива до позиции pos. Затем в ячейку pos записывается новое число x, после чего докопируются оставшиеся элементы.

Алгоритм Решения
Если вставляемый массив пуст, возвращается копия оригинального. Иначе создается результирующий массив размером arr.length + insertArr.length.С помощью System.arraycopy В него последовательно копируются: элементы arr до позиции pos, весь массив insertArr целиком в позицию pos, а затем хвост исходного массива arr.
